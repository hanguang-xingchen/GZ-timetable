# 被安排的一年

## 背景
从高三开始，我的高中(GZ)变本加厉地对我们进行虐待并压缩假期。喘息间，我下定决心，用这种简单直观且有贡献者独特风格的形式直接平铺展示这种侵蚀。详见[补充说明](HISTORY.md)

## 描述
一面 GitHub 风格的「年度时间墙」：把高三这一年的每一天，按五种颜色记下来，墙的尽头停在高考结束那天。它不是随日期滚动的日历，而是一张被慢慢填满、最终停在某个终点的倒计时。


## 几个特点

- 窗口固定、终点是硬边界：最后一列只画到高考结束当天
- 统计行自带「距离高考结束还有 N 天」
- 纯静态单文件，零 JavaScript

线上页面：<https://hanguang-xingchen.github.io/GZ-timetable/>

## 关于项目
这个项目的初衷是为了详尽地展示我校(GZ)对假期的侵蚀行为。由于时间和精力问题，我依照自己所需高度定制。若你也希望用这种方式揭露暴行，欢迎与我联系。联系方式详见[我的主页](https://hanguangxingchen.top)
